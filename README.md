## 👋 Hi, I'm Elias

I run **[AlphaCloud](https://alphacloud.bot)**, an all-in-one Discord bot with a web panel: moderation, tickets, giveaways, logging, levels, AI helpers and a lot more, configured in a browser instead of a wall of slash commands.

It is a one-person project, so everything here is something I decided, built and keep running myself: the bot, the API, the panel, the docs, the infrastructure.

<table>
<tr>
<td width="50%" valign="top">

### 🚀 What I'm working on

- **AlphaCloud bot** with multi-shard hosting and a module for almost every server need
- **Web panel** with a design system, live previews and a message builder
- **Scam Radar**, a privacy-first way to learn new scam texts across servers, no AI involved
- **Docs** in 21 languages, plus an in-panel setup assistant
- **Premium**, billing and the legal side done properly

</td>
<td width="50%" valign="top">

### 🧭 Principles

- Privacy by default: collect less, delete sooner
- Boring, reliable infrastructure over clever infrastructure
- Every user-facing text is translated, every error has an ID
- Small steps, verified, then shipped

</td>
</tr>
</table>

## 🧩 AlphaCloud at a glance

| | |
|---|---|
| 🛡️ **Moderation** | AutoMod, Anti-Nuke, warnings, scam detection |
| 🎫 **Support** | tickets with transcripts, suggestions, bug reports |
| 🎉 **Community** | giveaways, levels, reaction roles, minigames, birthdays |
| 🧾 **Logging** | detailed logs and message builder for everything the bot posts |
| 🤖 **AI helpers** | setup assistant and server builder, labelled and opt-in |
| 💎 **Premium** | monthly, prepaid and lifetime, fair-use limits for free servers |
